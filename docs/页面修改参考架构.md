# 页面修改参考架构

> 前后端分离落地后的分层归属速查。改页面时遵循"只动所属层"的边界约定。

## 分层归属（当前）

```
frontend/views/*.vue    → 前端页面（Vue3 + Naive UI，7 路由）
frontend/src/api/*.ts   → 前端 API 客户端（endpoints/http/tasks/events + 契约 types/schema）
api/routes/*.py         → FastAPI 路由层（/api/v1，薄转发：校验 + 调 services + 序列化）
api/tasks/*.py          → 异步任务（manager 单 worker + workers 注册表）
services/*.py           → 后端业务层（编排引擎，返回 dict，统一 {"ok":bool,"error":...}）
storage/*.py            → 后端数据层（SQLite / Chroma / hybrid）
core/*.py + utils/*.py + crawler/*.py → 后端引擎层（LLM Agent / 计量 / 抓取）
config/store.py + schema.py → 后端配置层
scheduler.py            → 后端常驻服务进程（API lifespan 拉起，可 CLI 独立运行）
data/ + config/*.yaml + .env → 后端运行目录
crawl.py/extract.py/index.py/qa.py/todo.py → CLI 入口（保留，复用同一 services）
```

## 页面 → 后端调用链（示例）

```
首页      /               HomeView.vue      → GET /notices/status-counts + /reminders/pending-count
通知浏览   /notices        NoticesView.vue   → GET /notices（分页）+ POST /tasks（抓取/提取/批量）
待办中心   /todos          TodosView.vue     → GET /todos + POST /todos/{id}/status + PATCH /todos/{id}
智能问答   /qa             QaView.vue        → GET /qa/ask/stream（SSE）
系统配置   /config         ConfigView.vue    → GET/PUT /config/* + POST /config/test-*
订阅管理   /subscriptions  SubscriptionsView.vue → POST /subscriptions/preview + POST /subscriptions（202 任务）
服务市场   /market         MarketView.vue    → POST /events（service_button_click 埋点）
```

## 约定

- 页面只 import 前端 api 客户端，不直连 storage/engine。
- 长耗时操作一律「提交任务 → 202 task_id → 轮询 GET /tasks/{id}」，页面用 `useTaskPoll`。
- 新增页面 = 前端加路由 + 后端加路由模块（`include_router(prefix="/api/v1")`）+ 更新 openapi.json 契约。
- 契约文件（openapi.json）是前后端唯一对齐点，改后端先导出契约再改前端类型。
