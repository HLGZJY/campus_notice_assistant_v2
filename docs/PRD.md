## 1. 背景与问题

### 1.1 用户痛点

大学生面临的通知信息过载问题：

- 通知分散在学校官网、学院网站、教务处、公众号等多个渠道
- 重要截止时间（报名、比赛、选课）容易错过
- 通知内容长，关键信息（时间、地点、链接）需要自己提炼
- 没有统一的地方管理"我需要做什么"

### 1.2 现有方案的不足

- 学校官网只有通知列表，没有个性化提醒
- 班级群转发容易漏看、被刷屏
- 手动记待办容易遗忘

## 3. 核心用户故事

### 故事 1：发现即将截止的报名

> 作为一名学生，我想看到"未来 7 天内截止的报名/活动清单"，这样我就不会错过重要截止时间。

**验收标准**：

- 系统自动从已抓取的通知中提取截止时间
- 按截止时间排序展示
- 即将截止（3 天内）的标红提醒

### 故事 2：结构化查看通知

> 作为一名学生，我想看到通知的关键信息（时间、地点、对象、链接）一目了然，而不是读完整篇通知。

**验收标准**：

- 每条通知展示结构化卡片：标题、类型、截止时间、地点、面向对象、报名链接
- 原文可折叠查看

### 故事 3：自然语言问答

> 作为一名学生，我想问"最近有哪些数学建模相关的通知？"，系统能基于已抓取的通知回答。

**验收标准**：

- 支持自然语言提问
- 回答基于已抓取的通知内容（RAG）
- 引用来源通知

### 故事 4：按兴趣筛选

> 作为一名学生，我只想看和我专业/兴趣相关的通知。

**验收标准**：

- 支持按通知类型筛选（竞赛、讲座、报名、行政）
- 支持关键词订阅

## 5. 通知类型分类

| 类型   | 代码             | 示例                     |
| ------ | ---------------- | ------------------------ |
| 竞赛   | `competition`    | 数学建模、创新创业大赛   |
| 讲座   | `lecture`        | 学术报告、校友分享       |
| 报名   | `registration`   | 选课、培训报名、活动报名 |
| 奖学金 | `scholarship`    | 国奖、校奖申请           |
| 行政   | `administrative` | 放假、注册、缴费         |
| 招聘   | `recruitment`    | 校招、实习信息           |
| 其他   | `other`          | 不属于上述类型           |

## 6. 非功能需求

| 维度     | 要求                       | 当前实现 |
| -------- | -------------------------- | -------- |
| 抓取频率 | 每小时一次（可配置）       | APScheduler crawl job，`crawl.interval_minutes` 可配置 |
| 响应时间 | 问答响应 < 10 秒           | SSE 流式逐 token 输出，首字更快 |
| 数据保留 | 通知保留 6 个月            | 过期清理默认只报告不删除（`cleanup_enabled=false`） |
| 并发     | MVP 单用户，后期支持多用户 | 单进程；异步任务单 worker 串行（规避 SQLite 单写者） |
| 部署     | 本地运行，Docker 可选      | Docker Multi-stage 镜像 + SPA 静态挂载 |
| 前端     | Web 界面                   | Vue3 + Naive UI（原 Streamlit 已被替换） |
| 后端     | API 服务                   | FastAPI + uvicorn（`/api/v1`） |

## 7. 约束

- LLM 供应商可配置（当前默认阿里云百炼 bailian qwen3.7-max，兼容 OpenAI 接口）
- Embedding 使用本地模型 `models/bge-small-zh-v1.5`（中文检索效果更好）
- 需遵守学校网站的爬取频率，避免压力
- 通知内容版权归原作者所有，仅用于个人学习

## 8. 成功指标（MVP + 后续实测）

| 指标               | 目标               | 实测 |
| ------------------ | ------------------ | ---- |
| 抓取成功率         | > 90%              | 每日体检监控（scheduler_log + health） |
| 结构化提取准确率   | > 80% 关键字段正确 | 黄金集 24/24（100%） |
| 问答相关性         | 主观评价 > 4/5     | 检索评测 20 题集 + 混合检索 |
| 截止时间提取准确率 | > 85%              | 黄金集 deadline 解析 100% |
