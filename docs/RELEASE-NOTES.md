# 版本更新日志（Release Notes）

> 记录对外发布的正式版本变更。桌面版 v0.2.0 为里程碑版本。

## v0.2.0 桌面版（2026-09-01）

**桌面版：从「终端 + 浏览器」升级为「原生 Windows 桌面应用」（仅 Windows x64）**

- **原生窗口**：pywebview 承载 UI，免终端、免浏览器独立启动（自动检测并静默安装 WebView2）。
- **系统托盘常驻**：托盘菜单五项（打开主界面 / 暂停调度 / 检查更新 / 打开日志目录 / 退出）；
  关闭窗口隐藏到托盘，后台调度继续运行。
- **单实例**：二次启动不重复开启，唤起已有主窗口。
- **开机自启**：设置页一键开关（写入当前用户启动项）。
- **更新闭环**：托盘/设置页「检查更新」，下载 + sha256 校验 + 确认安装。
- **数据目录三态**：程序与数据分离（`%APPDATA%\CampusNoticeAssistant\data`）；
  老版本 exe 同级 `data\` 自动迁移（只读复制、幂等、失败可回退）。
- **SQLite WAL + 自动备份**：读写并发更稳，每周一致性备份（保留 3 份）。
- **日志与崩溃兜底**：无控制台也可排障，`data\logs\app.log` + 崩溃转储 + 一键导出；
  未捕获异常自动落盘并弹窗。
- **调度空闲感知**：空闲才跑重活，检测到输入立即挂起，睡眠唤醒补偿。
- **通知中心**：站内通知未读徽标与已读持久化。
- **内存优化**：嵌入模型懒加载 + 空闲释放，长跑内存不劣化。
- **设置页桌面分组**：自启 / 启动方式 / 关闭行为 / 日志导出 / 检查更新集中管理。

**其它增强**

- 本地嵌入模型下载选项（设置页模型 tab 内直接下载，无需手动放模型文件）。
- 前端路由懒加载，产物体积下降（主 bundle 1732KB → 1517KB）。

**技术说明**

- 后端 68 个既有端点零改动；新增桌面控制面 `/api/v1/desktop/*` 与启动令牌校验。
- 测试：43 个离线验收测试全绿（含 10 个桌面壳用例），WAL/并发/向量一致性重点回归通过。

## v0.1.0（在线版基线）

**云端版（在线版）初始发布**

- 多源抓取 → LLM 结构化提取 → RAG 智能问答 → 待办管理 → 截止提醒 全链路。
